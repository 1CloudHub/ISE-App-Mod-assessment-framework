Session 2: Architecture & Code Review¶

Overview¶

The second session focuses on technical aspects of the legacy application, including architecture review and code analysis. This session provides a deeper understanding of the system's technical foundation and identifies potential challenges for modernization.

Pre-Session Activities¶

Assessment Team Preparation¶

  • Review provided source code repository
  • Analyze deployment architecture documentation
  • Use Amazon Q Developer CLI for initial code summarization
  • Prepare technical questionnaires for development team

Customer Team Preparation¶

  • Prepare system walkthrough overview
  • Ensure access to relevant code repositories
  • Gather deployment architecture diagrams
  • Identify technical SMEs for specific components

Session Activities¶

Code Walkthroughs¶

  • Review key application components and their responsibilities
  • Analyze code structure and organization
  • Identify coding patterns and anti-patterns
  • Assess technical debt and code quality

Architecture Dependency Mapping¶

  • Document current application architecture
  • Identify component dependencies
  • Map technology stack and frameworks
  • Analyze deployment and infrastructure components

Technical Constraint Identification¶

  • Document technical limitations of current architecture
  • Identify potential modernization challenges
  • Assess scalability and performance constraints
  • Evaluate security considerations

Deliverables¶

Architecture Assessment¶

The Architecture Assessment document includes: - Current architecture overview - Technology stack inventory - Technical debt assessment - Architectural constraints and limitations - Initial modernization recommendations

Container Diagram (C4 Level 2)¶

The Container Diagram visualizes: - Major system components (containers) - Technology choices for each container - Relationships between containers - External system interfaces

Next Steps¶

  • Prepare for workflow deep dives in Sessions 3-5
  • Identify specific workflows for detailed analysis
  • Schedule technical SMEs for workflow sessions
  • Distribute architecture assessment for review
