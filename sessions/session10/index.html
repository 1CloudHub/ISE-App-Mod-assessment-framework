Session 10: Microservices Design Workshop¶

Overview¶

Session 10 is a collaborative workshop focused on designing the microservices architecture for the modernized application. This session leverages the insights gathered in previous sessions to define service boundaries, interfaces, and interaction patterns that align with business domains and technical requirements.

Pre-Session Activities¶

Assessment Team Preparation¶

  • Analyze service boundary candidates and workflows
  • Prepare domain decomposition proposals
  • Create initial microservices design options
  • Prepare design workshop materials and exercises

Customer Team Preparation¶

  • Review domain boundaries and align technical SMEs
  • Identify business capabilities and their owners
  • Prepare for domain-driven design discussions
  • Review proposed service boundary options

Session Activities¶

Domain-Driven Design Exercise¶

  • Identify bounded contexts and domain models
  • Map business capabilities to potential services
  • Define ubiquitous language for each domain
  • Validate domain boundaries with business stakeholders

Microservices Definition¶

  • Define microservice responsibilities and boundaries
  • Identify service ownership and team alignment
  • Document service interfaces and contracts
  • Design service interaction patterns

Technical Architecture Design¶

  • Define data ownership and access patterns
  • Design communication patterns (sync/async)
  • Identify shared services and cross-cutting concerns
  • Design resilience and fault tolerance patterns

Deliverables¶

Microservices Design Document¶

The Microservices Design Document includes: - Service inventory and responsibilities - Domain model definitions - Service interface specifications - Data ownership and access patterns - Communication patterns and technologies - Resilience and scaling strategies - Service deployment and operational considerations

Component Diagrams (C4 Level 3)¶

The Component Diagrams visualize: - Internal components of each microservice - Service dependencies and interactions - API contracts and data flows - Shared components and libraries

Modernization Considerations¶

The session also addresses specific microservices implementation considerations:

  • Service discovery mechanisms
  • API gateway strategies
  • Event-driven communication patterns
  • Data consistency approaches
  • Distributed transaction handling
  • Observability and monitoring

Next Steps¶

  • Prepare for roadmap and risk planning in Session 11
  • Refine microservices design based on feedback
  • Identify pilot services for initial implementation
  • Distribute microservices design for stakeholder review
